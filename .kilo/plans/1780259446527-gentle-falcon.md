## Phase 5 — Reinstall frontend dependencies

```
cd frontend
nvm install 22.22.3
nvm use 22.22.3
rm -rf node_modules .next
npm cache verify
npm ci
```

If `package-lock.json` changed, inspect `git diff frontend/package-lock.json` — accept only lockfile metadata changes, not dependency version bumps.

## Phase 6 — Frontend build verification

```
npm --prefix frontend run typecheck
npm --prefix frontend run lint
npm --prefix frontend run build
npm --prefix frontend run test:contracts
```

Acceptance: all exit 0.

**Risk note:** `msw 3.x` interceptor has known issues with vitest/jsdom since Node 22 runtime changes. Build/lint/typecheck are independent of msw. Tests may need ignoring if `@mswjs/interceptors` causes failures — user has accepted this risk.

## Phase 7 — Backend tests

```
python3 -m pytest backend/tests
```

## Phase 8 — Delete and regenerate proof artifacts

```
rm -rf artifacts/proof/current
mkdir -p artifacts/proof/current
```

Run the canonical proof:
```
make proof
```

or:
```
bash scripts/package_and_validate_release_archive.sh \
  --archive-path dist/JUDGE_ATLAS-main-final-node22.zip \
  --package-root-name JUDGE_ATLAS-main
```

Run validators:
```
python3 scripts/check_required_proof_logs.py --strict-required-files
python3 scripts/check_proof_consistency.py
python3 scripts/verify_proof_hash_sync.py
python3 scripts/check_no_generated_files.py --root .
```

If `__pycache__` failures: `find . -type d -name "__pycache__" -prune -exec rm -rf {} +`
